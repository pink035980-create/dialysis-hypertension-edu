## 第一篇：認識透析高血壓——病理機制與血壓目標

### 第一章：洗腎病友血壓飆高的三大關鍵成因
血液透析患者的高血壓機轉與一般高血壓截然不同，主要源自三大生理因素：
1. **體液容積過度蓄積（佔 80% 以上）**：當腎臟失去排尿功能，喝進體內的水分與吃進的鹽分無法自然排出，滯留在血管中使循環血量劇增，如同過度充氣的水管，導致血壓持續攀升。
2. **交感神經系統活化**：病友常因擔心透析過程、扎針疼痛、環境吵雜或生活壓力，使交感神經處於過度亢奮狀態，誘發心跳加速與末梢小動脈強烈收縮。
3. **腎素-血管收縮素系統（RAAS）異常**：硬化的腎臟組織仍可能持續釋放腎素，促使血管收縮素濃度升高，進一步推高全身血管阻力。

### 第二章：洗腎病友的理想血壓標準值
臨床上常有病友誤以為「血壓越低越好」，這是極度危險的觀念！透析患者的血管往往伴隨動脈硬化，若血壓過低，心臟冠狀動脈與腦部血液灌流不足，極易引發心肌梗塞、缺血性中風或動靜脈瘻管血栓閉塞。

成大醫院依據實證醫學與臨床標準，訂定透析病友專屬血壓控制標準：
- **透析室診間血壓（透析前測量）**：建議控制在 **收縮壓 ＜ 140 mmHg、舒張壓 ＜ 90 mmHg**。
- **居家放鬆血壓（家中平日測量）**：建議維持在 **收縮壓 120～135 mmHg、舒張壓 60～80 mmHg**。
- **核心守則**：血壓追求的是「平穩最適」，絕非越低越好！

### 第三章：破除白袍效應——看見最真實的居家血壓
許多病友每次走進洗腎室，血壓計一夾往往飆破 160 甚至 180 mmHg，但回到家測量卻正常，這就是醫學上著名的**「白袍高血壓效應（White Coat Effect）」**。
- **機轉**：醫院環境的儀器聲響、護理人員走動、即將扎針的恐懼感，都會不自覺「活化交感神經，心跳加速」，使診間血壓虛高。
- **居家量測價值**：只有在家中熟悉、舒適、放鬆的環境下測量，才能真實反映心臟 24 小時的常態負荷。成大醫師需要參考您在家的平時紀錄，才能為您精準評估乾體重與開立最適劑量的降壓藥物。

## 第二篇：法寶一・落實居家血壓「722 原則」

### 第一章：黃金「722 原則」口訣與定義
國民健康署與台灣心臟學會大力推廣的「722 原則」，是每一位腎友必須銘記在心的控壓金科玉律：
- **「７」：連續記錄 7 天**——掌握完整一週（包含兩天洗腎間隔與週末長間隔）的血壓起伏波形。
- **「２」：每天量測 2 次**——分別在「晨起」與「睡前」各測量一次。
- **「２」：每次測量 2 遍**——每次量完第一遍後，靜坐間隔 1 分鐘，再量第二遍，取兩次的「平均值」記錄。

### 第二章：標準居家測量因果流程與正確坐姿
許多病友量血壓方式不正確，導致數值失真。請嚴格遵循以下因果順序：
1. **第一步：測量前先小便、靜坐休息 5 分鐘**。膀胱充盈憋尿會刺激交感神經使收縮壓飆高 10～15 mmHg；請先排空尿液，在有靠背的椅子上安靜休息 5 分鐘。
2. **第二步：晨起後一小時內測量一次**。在未吃早餐、未服藥、未做劇烈運動前，完成早晨測量。
3. **第三步：晚上睡覺前放鬆測量一次**。洗完澡放鬆、就寢前完成晚間測量。
4. **標準坐姿與壓脈帶配戴**：
   - 坐在有椅背的椅子上，雙腳平放地面，**切勿翹二郎腿**。
   - 壓脈帶綁於上手臂（避開動靜脈瘻管側，量非造管手），鬆緊度以可容納 1～2 指為宜。
   - 壓脈帶高度必須與**心臟處於同一水平線**。量測過程中保持安靜，不說話、不滑手機。

### 第三章：「桌曆打勾」與紀錄本的臨床重要性
- **養成「桌曆打勾」好習慣**：成大護理團隊建議將血壓紀錄本與桌曆擺放在客廳或床頭顯眼處。每次量完立刻在桌曆打勾並謄寫數值，預防漏量與遺忘。
- **回診必帶**：每次前來血液透析室或心臟科回診時，請務必將血壓紀錄本交給成大醫師與護理師查閱，這是醫療團隊調降體液與藥物處方的最關鍵指南。

## 第三篇：法寶二・乾體重與水分嚴格管理

### 第一章：心臟像氣球——脹大與驟縮的雙重危機
成大透析室常用「氣球」來比喻病友的心臟：
- **水喝太多（氣球過度脹大）**：若洗腎間喝水過量，微血管靜水壓驟增，水分滲入肺泡引發**急性肺積水**，躺下即喘（端坐呼吸）；心臟長期被反覆過度撐大，彈性疲乏，終將導致心臟肥大與充血性心力衰竭。
- **脫水太快（氣球劇烈驟縮）**：若洗腎間體重暴增 4～5 公斤，4 小時內必須高速抽乾水分，血管容積驟降，心臟瞬間抽縮，極易引發**痛苦的下肢肌肉痙攣（抽筋）、嚴重噁心嘔吐與危險性低血壓**。
- **維護之道**：唯有維持體內水分平衡，不讓心臟忽大忽小，才能保護心肌彈性，長青健康！

### 第二章：兩次透析間體重增幅不超 5%（水瓶比喻）
- **黃金安全界線**：兩次透析之間的體重增加，必須嚴格控制在**乾體重的 5% 以內**。
- **生活化大水瓶換算**：
  - 以乾體重 **60 公斤** 的病友為例：$60 \times 5\% = 3.0$ 公斤。
  - 相當於兩次洗腎之間，全身增加的水分與食物重量，最多只能等同於 **3 大瓶 1000cc 的市售瓶裝飲用水**！
  - **紅色警報**：嚴禁喝超過第 4 瓶！一旦進入第 4 瓶，即進入肺積水警戒區。

### 第三章：每日固定量體重的正確習慣
要精準控水，必須落實三個「同」：
1. **固定時間**：每天晨起、上完廁所、空腹時測量。
2. **固定磅秤**：在家使用同一台精準的電子體重秤。
3. **同套衣著**：穿著同套輕便衣褲測量，扣除厚重外套干擾。
- **警訊判讀**：若發現一兩天內體重暴增超過 1.5～2 公斤，代表水分已嚴重滯留，必須立刻節制飲水，不可拖延到洗腎日。

### 第四章：口渴不灌水四大妙招
透析長輩口乾舌燥時，切忌大口灌水。成大護理團隊傳授經過實證的「解渴四大妙招」：
1. **妙招 1：舌尖含一片天然薄檸檬片**——天然微酸能強烈刺激唾液腺自主湧出唾液，滋潤口腔；切記含片生津即可，勿榨汁大口飲用。
2. **妙招 2：口中含一顆小冰塊慢慢融化**——低溫能迅速消除喉嚨乾燥灼熱感，一顆 10cc 的小冰塊在口中慢慢融化，解渴效果勝過大杯水。
3. **妙招 3：嚼無糖薄荷口香糖或口香片**——透過持續咀嚼動作刺激口腔唾液分泌，並有效轉移想大口喝水的心理慾望。
4. **妙招 4：冷開水徹底漱口法（務必吐掉絕對不吞）**——含一大口常溫或冰涼開水徹底在口中咕嚕漱口，充分濕潤口腔黏膜後，**務必整口吐掉、絕對不吞下肚**；或用棉棒沾水輕抹雙唇，既能解渴潤唇，體重完全不增加！

## 第四篇：法寶三・飲食調味與限鹽禁忌

### 第一章：限水先限鹽——鈉離子鎖水機轉
- **科學原理**：許多病友抱怨「限水好痛苦、每天都好渴」，追查原因往往是「吃太鹹」！人體具有維持滲透壓的本能，**吃進 1 公克食鹽（含 400 毫克鈉），體內就必須鎖住約 100cc 的水分**。吃得鹹，大腦口渴中樞就會不斷發出喝水訊號。因此：**想成功限水，一定要先嚴格限鹽！**
- **每日鹽分上限**：洗腎病友每日食鹽攝取量應控制在 **5 公克以內（約相當於平平一啤酒瓶蓋或一平匙的鹽量）**。
- **高鹽地雷食品**：鹹菜、醬瓜、豆腐乳、香腸、臘肉、貢丸、泡麵湯底等加工醃漬品，皆為隱形高鈉重災區，務必忌口。

### 第二章：重大醫學警告——嚴禁使用市售低鈉鹽
這是透析室最致命、最常引發急診急救的陷阱！
- **市售低鈉鹽的危險秘密**：市售標榜健康的「低鈉鹽、美味鹽、薄鹽醬油」，其原理並非減少鹹味，而是以**「氯化鉀（KCl）」取代傳統的氯化鈉（食鹽）**。
- **致命高血鉀機轉**：正常人的多餘鉀離子 90% 由腎臟隨尿液排出；但透析病友腎功能喪失，無法自然排鉀。一旦食用低鈉鹽，血鉀濃度會在數小時內暴飆至 6.5～7.0 mmol/L 以上！
- **臨床嚴重後果**：高鉀會直接麻痺心臟肌肉、干擾心電傳導，在毫無前兆下**瞬間誘發惡性心律不整、心室顫動甚至心跳驟停猝死**！
- **鄭重醫囑**：洗腎病友與家庭採買者，**嚴禁購買、嚴禁使用任何市售低鈉鹽與美味鹽！**

### 第三章：天然辛香料提味技巧
不用低鈉鹽、少用食鹽，食物會不會食之無味？成大營養與護理團隊建議運用大自然恩賜的天然辛香料：
- 烹調時善用**青蔥、老薑、生大蒜、鮮檸檬汁、洋蔥、香菜、九層塔、八角、白醋**等天然食材提味。
- 利用香氣喚醒味蕾，酸甜引出食物原本鮮甜，減鹽美味、安全不傷心！

## 第五篇：法寶四・安全遵醫囑吃藥四部曲

### 第一章：拿取藥盒吃藥動作四部曲
降壓藥物是守護血管的鋼鐵防線，長輩吃藥請落實標準動作四部曲：
1. **第一步【拿取藥盒・不吃錯】**：核對今天星期幾與早晚藥格，手拿處方籤確認藥物種類與顆數。
2. **第二步【倒出藥物於乾淨掌心】**：將當次所需藥物倒於清潔手掌心，確認無誤。
3. **第三步【配一口常溫開水嚥服】**：放緩動作，配一口常溫開水順暢嚥下，嚴防嗆咳。
4. **第四步【撫胸順氣比個讚】**：輕撫胸口確保藥物順利滑入胃部，呼吸平穩，給自己一個讚！

### 第二章：破除「血壓正常就停藥」的致命迷思
臨床上常有病友自作主張：「護理師，我今天早上量 128/75 很正常，所以我今天降壓藥就不吃了。」這是極為危險的錯誤行為！
- **真相揭曉**：**血壓之所以正常，正是因為藥物在體內持續提供保護！**
- **擅自停藥惡果**：降壓藥藥效消退後，血管會產生猛烈的反彈性收縮，血壓往往在傍晚或深夜急速飆破 180～200 mmHg，極易誘發急性腦中風、腦出血或主動脈剝離。
- **正確做法**：天天固定吃藥，未經成大醫師專業評估，**絕不擅自減藥或停藥**！

### 第三章：洗腎當天早晨吃藥的遵醫原則
- 血液透析過程中，體內多餘的水分會被機器逐步抽出，血壓通常會自然下降。
- 因此，部分長效型或強效降壓藥，成大醫師會特別交代在「洗腎當天早晨先暫停服用一次」或改到「洗腎結束後服用」，以避免透析進行中血壓過低。
- **遵醫囑原則**：洗腎當天早上的吃藥時間與種類，請務必嚴格遵照成大透析室醫師開立之個別化處方指示，切勿自行猜測。

## 第六篇：總結——控壓四句訣與緊急諮詢

### 第一章：透析控壓四句訣大回顧
請各位腎友與家屬一起朗讀成大透析室控壓四句訣：

```
┌────────────────────────────────────────────────────────┐
│             ★ 血液透析患者・控壓四句訣 ★             │
├────────────────────────────────────────────────────────┤
│  一、居家量七二二：連續七天、早晚量、每次量兩遍。      │
│  二、體重不超過五：兩次透析間，增幅小於乾體重 5%。     │
│  三、減鹽禁用低鈉：每天鹽少於五克，嚴禁市售低鈉鹽。    │
│  四、吃藥遵照醫囑：固定吃藥不擅停，洗腎早晨遵醫囑。    │
└────────────────────────────────────────────────────────┘
```

### 第二章：危急警訊與緊急就醫指南
當您在家中或透析間歇期，出現下列任一警訊徵兆時，代表心血管或水分負荷已達危險邊緣，請立即聯絡成大血液透析室或前往急診就醫：
1. **急性呼吸困難與喘促**：無法平躺入睡，必須坐起才能呼吸（端坐呼吸），伴隨咳嗽與粉紅色泡沫痰（急性肺積水徵兆）。
2. **血壓異常暴飆或暴跌**：居家收縮壓高於 180 mmHg 伴隨劇烈頭痛、視力模糊；或收縮壓低於 100 mmHg 伴隨冷汗、頭暈暈眩。
3. **下肢與面部嚴重凹陷性水腫**：手指按壓小腿骨前皮膚，凹陷無法立刻回彈。
4. **心悸與心律不整徵兆**：心臟漏拍、胸悶、極度無力、四肢發麻（高血鉀危機）。
